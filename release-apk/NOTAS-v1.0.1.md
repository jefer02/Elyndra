A small update to Elyndra 1.0: a fix for typing in Settings and a cleaner color picker.

## What's new
- **Fixed:** tapping a text field in Settings (metadata accounts, API keys) now opens the keyboard. Before, focus could jump back to the Settings menu.
- **Redesigned color samples:** palettes and accent colors use compact swatches that fit on one row and adapt to the screen width.
- **Tidier Settings layout:** the side menu, row heights and spacing adapt better to tablets and handhelds.
- **Accessibility:** every color sample has a readable name for screen readers, in all six languages.
- Show/hide toggle on password fields.

## Download
- **Elyndra-v1.0.1-arm64-v8a.apk**: most phones, tablets and handhelds (smaller).
- **Elyndra-v1.0.1-universal.apk**: if you're not sure; bigger, works on every device.

Already on 1.0.0? Open **Settings → About → Updates → Check now**, or just wait for the automatic check.

Requires Android 8.0 (API 26) or later.
